Privacy Policy

ActionFi Verification Bot · Last updated: October 12, 2026

This policy explains what data the ActionFi Verification Bot ("the Bot") collects, why, and how you can have it removed. By using the Bot's features (clicking a verification button, entering a code, or running a command), you agree to this policy.

What the Bot does

The Bot verifies membership across Discord servers for partnership campaigns, runs an anti-bot visual verification gate, redeems one-time access codes, and provides role-assignment panels. It is operated by the ActionFi and Action Model communities.

Data we collect

  • Discord user ID and your username at the time you verify.
  • Linked username, if you choose to set one with /link-username.
  • Campaign membership status: whether you are a member of each server a campaign requires, whether you are eligible, and the server where you first verified.
  • Timestamps of when you verified and when your status was last checked.
  • Access code redemptions: which code was redeemed, by which user, and when.
  • Server configuration set by admins: server ID, log channel, role and panel settings.
  • Activity logs posted to a log channel chosen by each server's admins (for example, "user verified" or "role assigned").

The Bot does not read message content, track your online status or activity, or send direct messages. It does not collect email addresses, passwords, wallet keys, or payment information.

Why we need it

The Bot uses Discord's Server Members permission to check whether you belong to each server a campaign requires, and to detect when you leave one so your role and eligibility can be removed automatically. Data is used only to run verification, assign and remove roles, redeem codes, and produce eligibility reports for campaign admins.

How data is shared

We do not sell your data or use it for advertising. Eligibility lists (user ID, username, linked username, and verification status) may be exported by authorized campaign admins for the purpose of running the campaign. Data may also be disclosed if required by law. Data is stored with our hosting and database providers (Railway) solely to operate the Bot.

Retention

Campaign and verification records are kept for as long as needed to run and audit the campaign, and then deleted when no longer needed or when you ask us to delete them (see below).

Your choices and deletion requests

You can ask us at any time to access, correct, or delete the data we hold about you. Send a request from the Discord account concerned, or include your Discord user ID, using the contact below. We will respond within a reasonable time. You can also remove the Bot's role from yourself or leave a participating server; leaving a required server automatically revokes your eligibility.

Security

Data is stored in a private database with restricted access. No system is perfectly secure, but we take reasonable steps to protect it.

Children

The Bot is intended for users who meet Discord's minimum age requirement. We do not knowingly collect data from anyone under that age.

Changes

We may update this policy and will change the date above when we do. Continued use of the Bot means you accept the updated policy.
